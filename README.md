# ControlCenter Releases

Публичный mirror релизных артефактов проекта **ControlCenter** (десктопное Tauri-приложение для Linux). Исходный код находится в приватном репозитории; здесь публикуются только готовые сборки.

Сюда автоматически выкладываются:
- `*.AppImage` — дистрибутив для Linux (поддерживает auto-update через Tauri Updater Plugin)
- `*.AppImage.sig` — подпись ed25519
- `latest.json` — манифест с актуальной версией

Установленные пользователями экземпляры приложения проверяют этот репозиторий, чтобы обнаружить новые версии и предложить обновление с проверкой подписи.
